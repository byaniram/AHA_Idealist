The target variable Inflation_Level is derived by categorizing changes in “House Rent” as a proxy for inflation levels.

The Decision Tree Classifier models how CPI components like Food, Medical Insurance, Electricity, etc. can influence inflation levels.

Feature importance shows which CPI elements most strongly affect inflation classification. Plots are added to visualize the confusion matrix, feature importance, and the Decision Tree structure.

# Step 2: Data preprocessing

# Convert observation_date to datetime and extract year
df['observation_date'] = pd.to_datetime(df['observation_date'])
df['Year'] = df['observation_date'].dt.year

# Create an example 'Inflation_Level' classification target
# Classify inflation level based on CPI change rate
df['Inflation_Level'] = pd.qcut(df['HouseRent'].pct_change().fillna(0), q=3, labels=['Low', 'Medium', 'High'])

# Drop missing values
df = df.dropna()

# Step 3: Feature selection

features = [
    'MedicalInsurance', 'Recreation', 'Food&Beverages',
    'Tuition&ChildCare', 'Airfare', 'HouseRent',
    'Electricity', 'Auto_Fuel', 'Cable&Communication'
]

X = df[features]
y = df['Inflation_Level']

# Scale the features
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# Split dataset

X_train, X_test, y_train, y_test = train_test_split(
    X_scaled, y, test_size=0.3, random_state=42, stratify=y
)
# Decision Tree Classifier

dt_model = DecisionTreeClassifier(
    criterion='entropy', max_depth=9, random_state=42
)
dt_model.fit(X_train, y_train)

# Evaluation

y_pred = dt_model.predict(X_test)

print("\nClassification Report:\n", classification_report(y_test, y_pred))
print("Accuracy Score:", accuracy_score(y_test, y_pred))

Evaluation Metrics - F1 Score and Recall

The F1-score balances both false positives and false negatives Recall measures how many of the actual “positive” (or high inflation) cases were correctly identified.

In [ ]:

from statsmodels.tsa.holtwinters import ExponentialSmoothing

Prepare the data for processing

In [ ]:
# Convert observation_date to datetime and set as index

df['observation_date'] = pd.to_datetime(df['observation_date'])
df = df.sort_values(by='observation_date')
df.set_index('observation_date', inplace=True)

# House Rent is the representative component
ts = df['HouseRent']

# Apply Exponential Smoothing Model

# Fit model with trend and seasonality detection
model = ExponentialSmoothing(
    ts,
    trend='add',             # captures upward/downward trend
    seasonal='add',          # additive seasonality
    seasonal_periods=12      # adjust based on monthly data
).fit()

Evaluation Metrics - MSE and RMSE

  1. Mean Squared Error (MSE) quantifies the average squared difference between the actual and predicted (fitted) CPI values.

  2. Root Mean Squared Error (RMSE) RMSE is the square root of MSE, bringing the error value back to the same unit as the CPI index
